# Coral CLI

A blazing-fast command-line tool that scaffolds new Astro projects, adds integrations, and manages content collections without ever leaving the terminal.

## Why I built it

I found myself repeating the same setup steps for every new project. Coral CLI turns that boilerplate into a single command.

## Features

- Interactive project scaffolding
- One-command integration installs
- Theme and component templates
- Written in Rust with zero runtime dependencies
