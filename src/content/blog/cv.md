## The pain

Searching for a job is a tedious process. An important part of it is customizing your cv to enhance those skills each offer asks in order to be a better fit. The most common way of doing this is just manually modifing a .docx or google docs file each time, making copies and customizing them.

This has several problems, lets say we have a template for th cv, we create 2 different cvs for different purposes, for example one centered in backend development and another one focused in gamedev.

If we decide we want to change, just the color of it, we have to go one by one changing the color by hand. Multiply this by 5/10 different cvs and you have a headeache each time you want to modify anything. Not to say if having a different version of each one in different languages if wanting to apply in lets say english and spanish.

## What do I needed

I need a system for:
- PDF generation of my cv
- Good readeability by machines
- Easy to modify
- Handle multiple versions
