# Coral Terminal Dev

A portfolio starter theme with a developer terminal vibe. It pairs a monospace type aesthetic with clean block-based layouts built on Tailwind and DaisyUI.

## What's inside

- Four-section layout (projects, blog, contact)
- Content collection powered projects and posts
- Fully themeable via DaisyUI
- JetBrains Mono throughout for cohesion
