# Coral Blog Engine

A minimal, markdown-first blog engine built on Astro's content layer. No database, no build pipeline magic — just drop in `.md` files and get a searchable, taggable blog.

## Highlights

- Content collection driven
- Client-side tag and year filtering
- Full-text search without external services
- Zero-JS page output by default
